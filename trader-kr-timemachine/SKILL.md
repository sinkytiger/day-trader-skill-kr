# trader-kr-timemachine

타임머신은 돈을 걸기 전에 묻는다: 이 종목이 최근 60 거래일 동안 보인 움직임만으로 남은 장을 다시
만들면, 이 손절과 목표는 어느 쪽이 먼저 오는가. 10,000번 다시 만들고, 같은 규칙이 지난 거래일에
실제로 어땠는지도 센다. 답이 동전 던지기에 가까우면 그렇다고 말한다. 그게 이 스킬의 쓸모다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/timemachine.py" run                     # trader-kr/plan.json, 10,000회, 시드 19
python "${CLAUDE_SKILL_DIR}/timemachine.py" run --write             # trader-kr/timemachine.json 에도 저장
python "${CLAUDE_SKILL_DIR}/timemachine.py" run --until 15:15       # 청산 시각에서 멈춤
python "${CLAUDE_SKILL_DIR}/timemachine.py" run --sessions 120      # 재생 재료를 120 거래일로
python "${CLAUDE_SKILL_DIR}/timemachine.py" run --history-sessions 250   # 과거 재적용을 1년치로
python "${CLAUDE_SKILL_DIR}/timemachine.py" run --block 12          # 묶음 재생을 1시간 단위로 (0 이면 끔)
python "${CLAUDE_SKILL_DIR}/timemachine.py" chart --from            # 저장한 결과의 경로 부채꼴 (ASCII)
python "${CLAUDE_SKILL_DIR}/timemachine.py" run --symbol 005930 --date 2026-10-28 --entry 72300 \
    --stop 71700 --target 73500 --entry-time 10:15
```

## 읽고 쓰는 것

| 파일 | 내용 |
| --- | --- |
| `trader-kr/plan.json` | 청산 계획 (진입, 손절, 목표, 진입 시각, 시가 범위, 손절 규칙, 가격제한, 비용률) |
| 토스증권 1분봉 | 계획일 전 약 `(--sessions 와 --history-sessions 중 큰 값) x 1.55 + 12` 일. 처음 한 번만 받고 `trader-kr/cache/` 에서 다시 쓴다 |
| DART 공시 목록 | `DART_API_KEY` 가 있으면 계획일의 그 종목 공시를 찾아 경고 (막지 않음) |
| `trader-kr/timemachine.json` | `--write` 때: 결과 전체 (재생 분포, 경로 띠, 과거 거래 목록, 판정) |

기본값(과거 재적용 120 거래일)으로 처음 돌리면 종목당 1~4분 걸린다 (2026-10-29 실측 78~226초). 그다음부터는 캐시라
1~2초다. 처음 받는 동안 진행 상황을 찍으니 사용자에게 미리 말한다.

## 방법 (원본 sim.py 와 같은 알고리즘, 같은 난수 순서)

1. 1분봉을 5분봉으로 묶는다. **온전한 거래일**만 쓴다: 09:00 ~ 15:20 5분봉 76개가 다 있고 첫 봉에 거래가
   있는 날. 개장이 늦은 날(신년 첫 거래일, 수능일)과 빈 봉이 있는 날은 빼고 무엇을 뺐는지 말한다.
2. 재료: 봉 자리 1..75 마다 지난 거래일의 그 자리 봉을 직전 봉 종가에 대한 비율로 모은다.
3. 한 번의 재생: 진입가에서 시작해 남은 봉마다 같은 시각 +-2 봉 안의 재료 하나를 골라 곱한다. 가격은
   계획일 상·하한가 안으로 자른다. 한 봉 안에서 손절을 먼저 본다. 둘 다 닿은 봉은 손절로 센다 (보수적).
4. 결과: 목표 먼저, 손절 먼저, 둘 다 아님 (15:20 까지 열림). R 은 목표면 목표 R, 손절이면 -1, 아니면
   (15:20 가격 - 진입가) / 위험. 비용 뺀 R 은 수수료와 매도 거래세를 뺀다.
5. 과거: 계획의 규칙 (같은 시가 범위 길이, 같은 손절 규칙, 같은 목표 R) 을 그 거래일마다 다시 적용한다.
6. 판정: 한쪽에 닿은 재생 중 목표 비율을 본전 비율 1 / (1 + R) 과 비교한다. 5%p 미만이면 동전 던지기
   (1R) 또는 본전에 가까움, 15%p 이상이면 "강하게".

원본에 없는 보조 결과 (판정은 원본 방식으로만 낸다):

- **30분 묶음 재생** (`--block 6`). 봉을 하나씩 따로 고르지 않고 같은 거래일의 연속 봉 6개씩 이어 붙인다. 시각은
  맞춘다. 같은 날 안의 변동성 군집과 짧은 추세가 남는다. 원본 방식과 목표·손절 비율이 5%p 넘게 다르면 알린다.
- **긴 과거 재적용과 구간** (`--history-sessions 120`). 재료(60 거래일)보다 긴 기간에 규칙을 다시 적용하고, 목표 비율의
  95% 윌슨 구간과 평균 R 의 95% 부트스트랩 구간을 붙인다. 구간이 본전 비율을 포함하면 "표본으로는 본전과 구별되지
  않는다" 고 말한다.
- **그날 공시.** `DART_API_KEY` 가 있으면 계획일의 그 종목 공시(잠정실적, 증자, 해명 공시 등)를 찾아 경고한다.

20 거래일보다 적거나 진입 봉이 자료에 없으면 이유를 말하고 멈춘다. 5분봉 계획만 돌린다.

## 절차

1. `/trader-kr-exit` 로 계획을 만든 뒤 `timemachine.py run` 을 돌린다.
2. 사용자에게 네 줄로 말한다: 목표 먼저, 손절 먼저, 둘 다 아님, 판정. 비용 뺀 평균 R 이 0 이하면 꼭 말한다.
   묶음 재생이 크게 다르다는 줄이 있으면 그것도 말한다.
3. 과거 재적용 줄을 말한다: 몇 번 신호, 목표·손절·둘 다 아님, 평균 R 과 그 구간. 구간이 본전을 포함하면 그렇다고 말한다.
   그날 공시 경고가 있으면 빼지 않는다.
4. 결과가 손절 쪽이면 거래를 건너뛰는 것도 답이라고 말한다. 숫자로 사라고 권하지 않는다.
5. 다음은 `/trader-kr-budget`.

## 예시 (합성 자료)

시험용 합성 종목 SYN001. 실제 시세가 아니라 무작위 걸음이라 결과도 의미 없다. 출력 모양만 본다.

```
남은 장 10:15 ~ 15:20 (5분봉 61개)를 10,000번 재생, 시드 19.
  목표 먼저     23.0%
  손절 먼저     61.2%
  둘 다 아님    15.8%   15:20 까지 열려 있음
  평균 R: -0.073 (...). 비용 뺀 평균 R: -0.273 (수수료 0.015%, 매도세 0.20%).
과거: 같은 규칙 ... 그 60 거래일에 적용하면 48번 신호: 목표 11, 손절 35, 둘 다 아님 2.
손절 쪽으로 기웁니다: 2R 에서는 한쪽에 닿은 재생 중 목표가 33% 는 먼저 와야 본전인데 27% 였습니다.
```

`--history-sessions 61` 로 돌리면 아래 줄이 더해진다.

```
30분 묶음 재생 (같은 거래일 봉 6개씩 이어 붙임, 변동성 군집과 짧은 추세를 남김):
  목표 먼저 21.2%, 손절 먼저 62.3%, 둘 다 아님 16.5%. 평균 R -0.116, 비용 뺀 평균 R -0.316.
      평균 R 95% 구간 -0.604 ~ +0.135, 비용 뺀 평균 R 95% 구간 -0.951 ~ -0.232 (부트스트랩).
과거 재적용의 목표 비율 26% 는 95% 구간 15~40% 가 본전 33% 를 포함합니다. 표본으로는 본전과 구별되지 않습니다.
```

## 한계 (사용자에게 줄이지 않고 말한다)

- 원본 방식은 봉을 서로 독립으로 고른다. 묶음 재생이 이를 일부 보완하지만, 30분보다 긴 추세와 날짜 사이 흐름은 여전히 없다.
- 실적 발표, 공시, 거래정지, VI 단일가, 상·하한가 잔량 같은 사건은 재료에 없으면 만들지 못한다. 공시 경고는 그날
  사건이 있다고 알릴 뿐 그 영향을 재생에 넣지는 않는다.
- 과거 재적용은 120 거래일이면 신호가 수십 건이다. 2026-10-29 대형주 네 종목에서 구간이 모두 본전을 포함했다.
- 토스증권 1분봉은 KRX 와 NXT 통합 시세다. KRX 만의 가격과 조금 다를 수 있다.
- 모의이지 예측이 아니다. 같은 시드면 같은 숫자일 뿐이다.

## 안전

- 교육과 도구일 뿐 투자 권유가 아닙니다 (not financial advice). 판정은 모의 결과이지 추천이 아닙니다.
- 1단계에는 주문을 보내는 도구가 없습니다. 이 팩의 어떤 스크립트도 토스증권 주문·계좌 API 를 부르지 않습니다.
- 토스증권 Open API 에는 모의투자 서버가 없습니다. 나중에 주문 단계를 붙여도 기본값은 보내지 않음
  (`"send_orders": false`) 이고, 주문은 세 가지가 모두 맞을 때만 나갑니다: trader-kr-risk 가 오늘 그 주문
  그대로 통과시켰고, 사용자가 채팅에서 그 주문 하나에 yes 라고 했고, Claude 의 도구 승인 카드에서 한 번만
  허용을 눌렀을 때.
- 미수, 신용, 공매도는 쓰지 않습니다.
- 토스증권 client_id 와 client_secret 은 `~/.tossinvest/credentials.json` 또는 환경변수에 두고 채팅에 붙여 넣지 않습니다.
- 토스증권 자료는 본인 매매 목적으로만 씁니다. `trader-kr/cache/` 를 공유하거나 저장소에 올리지 않습니다.
