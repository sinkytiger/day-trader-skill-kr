# trader-kr-news

차트가 좋아 보여도 장 마감 뒤에 나온 유상증자, 다음 날 아침의 잠정실적, 거래소의 매매거래정지 하나로 가격이
손절가를 건너뛸 수 있다. 셋업이 거래가 되기 전에, 관심 종목마다 회사가 금융감독원에 낸 공시(DART)를 읽고
새로 나온 것만 알려 준다.

원본(미국판 trader-news)은 Yahoo 뉴스 제목과 SEC 8-K 를 읽었다. 국내판은 DART 공시만 읽는다. 뉴스 제목은
출처와 정확도가 제각각이라 넣지 않았다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/news.py"                                  # 관심 종목의 새 공시
python "${CLAUDE_SKILL_DIR}/news.py" --symbols 005930 000660 --days 5
python "${CLAUDE_SKILL_DIR}/news.py" --all --json                     # 이미 본 것까지, 기계용
python "${CLAUDE_SKILL_DIR}/news.py" market                           # 시장 전체 ! 공시 (유가·코스닥)
python "${CLAUDE_SKILL_DIR}/news.py" read 20261120800721              # 공시 원문
python "${CLAUDE_SKILL_DIR}/news.py" read 20261120800721 --find 취득예정일자
```

`--dry-run` 은 본 것으로 기록하지 않고, `--now "2026-11-20 08:30"` 은 시계를 고정한다 (한국 시간).
종료 코드는 새 공시가 있으면 0, 없으면 1, 오류는 2.

## 읽고 쓰는 것

| 파일 / 자료 | 무엇 |
| --- | --- |
| `--symbols`, 없으면 `trader-kr/watchlist.json` | 스캐너 결과 (`hits[].symbol`) |
| `trader-kr/plan.json`, `trader-kr/today/<종목>/plan.json` | 청산 계획의 종목 |
| `trader-kr/journal.jsonl` | 아직 청산하지 않은 거래의 종목 |
| OpenDART 공시검색 (`list.json`) | 그날 전체 공시 목록. `trader-kr/cache/dart/YYYYMMDD.json` 에 두고 오늘 것은 10분마다 다시 받는다 (위험 점검과 같은 캐시) |
| OpenDART 공시서류원본파일 (`document.xml`) | `read` 의 원문 ZIP. `trader-kr/cache/dart/docs/` 에 둔다 |
| `trader-kr/state/news.json` | 보여 준 접수번호 (30일) |

기간은 바로 앞 평일부터 오늘까지다 (월요일이면 금요일부터). 장 마감 뒤에 나온 공시가 다음 날 시가를 흔들 수 있어서다.
공휴일이 끼면 `--days` 나 `--since` 로 늘린다. DART 목록에는 접수 날짜만 있고 시각은 없다.

## 규칙

- **공시 제목은 단서다.** 무슨 일이 있었는지 말하기 전에 `read` 로 원문을 읽는다. 숫자와 날짜는 원문에서 옮기고
  접수번호와 링크를 단다. 원문을 읽지 못했으면 읽지 못했다고 말한다.
- **정정을 본다.** `[기재정정]` 은 앞서 낸 공시를 고친 것이다. 원문의 "정정전 / 정정후" 를 읽고 무엇이 바뀌었는지
  말한다. 비고에 "뒤에 정정 있음" 이 붙은 공시는 그 뒤 정정 공시가 최종이다.
- **무엇에 닿는지 말한다.** 공시마다 종목과 꼬리표가 붙는다. ! 는 단타 전에 꼭 볼 공시다: 잠정실적과 손익구조
  변경, 유상증자·전환사채·신주인수권·교환사채·감자, 최대주주변경, 매매거래정지·관리종목·상장폐지·상장적격성,
  불성실공시와 조회공시, 횡령·배임·회생·파산·부도, 감사의견 거절, 공개매수·합병·분할, 단일판매·공급계약,
  임원·주요주주 거래계획보고.
- **예측하지 않는다.** 무엇이 공시됐는지만 말한다. 주가가 어떻게 될지는 말하지 않는다.
- **개인 정보는 가린다.** 임원·주요주주 보고서 원문의 생년월일(등록번호), 주소, 전화번호, 이메일, 업무 연락
  담당자 이름은 `read` 가 가린다. 가린 것을 다른 곳에서 찾아 채우지 않는다.

## 단계

1. `python "${CLAUDE_SKILL_DIR}/news.py"` 를 돌린다. 장 전에는 `market` 도 함께 본다.
2. ! 공시, 거래소조치, 자금조달, 법률·위험 꼬리표를 먼저 `read` 로 읽는다.
3. 종목마다 짧게 적는다: 무엇이 공시됐는지(원문의 숫자와 날짜), 접수번호와 링크, 셋업에 왜 중요한지 한 줄
   (예: "잠정실적이 오늘 장 중에 나올 수 있어 손절가를 건너뛰는 갭이 날 수 있습니다"). 새 공시가 없는 종목은
   없다고 말한다.
4. 공시가 그림을 바꾸면 `/trader-kr-entry`, `/trader-kr-exit` 전에 먼저 말한다. 공시 하나만 보고 사거나 팔라고
   하지 않는다.

장 중에는 `/loop 15m /trader-kr-news` 나 아침 예약 작업으로 돌린다. DART 목록은 10분마다만 새로 받는다.

## 예: 2026-11-21 에 돌린 것

`news.py --symbols 005930 000660 035720 --since 2026-11-18` 의 SK하이닉스 줄:

```
000660 SK하이닉스
    2026-11-20 [정정, 계약·투자] [기재정정]타법인주식및출자증권취득결정  (유가)
      https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20261120800721  접수번호 20261120800721
```

`read 20261120800721` 의 원문은 2018-05-31 에 낸 타법인 주식 취득결정의 정정이다. 정정 사유는 "전환사채의 전환권
행사" 이고, 취득방법이 "전환사채 취득" 에서 "전환사채의 전환권 실행" 으로, 취득예정일자가 2018-06-01 에서
2026-12-04 로 바뀌었다. 제목만 보면 새 취득 결정 같지만, 원문은 2018년 결정을 고친 것이고 바뀐 내용은 그때 산
전환사채를 주식으로 바꾸는 일이다. 요약은 그렇게 쓴다.

## 하지 않는 것

- 공시 내용, 인용, 숫자를 지어내거나 부풀리지 않는다.
- 공시를 근거로 사거나 팔라고 하지 않고, 주문을 내지 않는다.
- 서버를 두드리지 않는다. 목록은 하루에 한 번 받아 캐시에 두고 (오늘 것은 10분마다), 쪽 사이에 쉰다.
