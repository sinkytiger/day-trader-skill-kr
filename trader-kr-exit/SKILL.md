# trader-kr-exit

청산 계획은 사기 전에 두 가격을 정한다. 틀렸다고 인정하고 나올 손절가와, 이겼다고 보고 나올
목표가. 그리고 둘 다 안 오면 나올 시각. 진입 뒤에 정한 손절은 대개 너무 멀리 간다. 그래서 여기서
먼저 정하고, 정한 뒤에는 더 멀리 옮기지 않는다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/exit.py" plan                                  # trader-kr/entry.json, 범위 중간 손절, 2R
python "${CLAUDE_SKILL_DIR}/exit.py" plan --stop or-mid --target 1R --write
python "${CLAUDE_SKILL_DIR}/exit.py" plan --symbol 005930 --entry 72300 --or-high 72100 --or-low 71400
python "${CLAUDE_SKILL_DIR}/exit.py" plan --stop atr:1.5                   # 그날 5분봉 ATR
python "${CLAUDE_SKILL_DIR}/exit.py" plan --symbol 000660 --entry 201000 --setup level --stop pct:1
python "${CLAUDE_SKILL_DIR}/exit.py" show
```

그 밖의 옵션: `--flat-by HH:MM`, `--prev-close 가격` (상·하한가 추정), `--no-network`, `--offline FILE`
(atr 손절용 1분봉), `--now`, `--json`.

## 읽고 쓰는 것

| 파일 | 내용 |
| --- | --- |
| `trader-kr/entry.json` | 진입 타이머 결과. 신호가 아니면 `--entry` 를 줘야 미리 계획한다 |
| `trader-kr/config.json` | `flat_by` (15:15), `min_reward_risk` (1.0, 순손익비 기준), `commission_rate`, `sell_tax_rate` |
| 토스증권 상·하한가 | 오늘 계획이면 받는다. 지난 날은 `--prev-close` 로 추정 |
| 토스증권 1분봉 | `--stop atr:K` 일 때만, 진입 봉까지 |
| `trader-kr/plan.json` | 손절, 목표, 주당 위험, 손익비, 순손익비, 주당 비용, 청산 시각, 가격제한, 장 시간 |

## 규칙

- **손절은 호가 단위로 내린다.** 진입가에서 멀어지는 쪽. 30,145.5원이면 50원 단위로 30,100원.
- **목표는 호가 단위로 반올림한다.** 2R 이면 진입가 + 2 x (진입가 - 손절가).
- **호가 사이 체결가는 위 호가로 올린다.** 토스증권 1분봉에는 245,250원처럼 호가 사이 가격이 섞여 나온다
  (중간가 체결). 시장가로 사면 매수 호가에 체결되므로 바로 위 호가 245,500원을 진입가로 계산하고 그렇다고 말한다.
- **너무 좁은 손절은 거절한다.** 호가 2칸 또는 가격의 0.05% 보다 좁으면 보통 흔들림에도 손절된다.
- **비용.** 순손익비 = (목표 - 진입 - 목표 때 비용) / (위험 + 손절 때 비용). 비용은 매수 수수료,
  매도 수수료, 매도 거래세 (기본 0.015%, 0.015%, 0.20%). 손절 때 비용이 위험의 절반을 넘으면 경고한다.
- **가격제한폭.** 목표가가 오늘 상한가보다 높으면 닿을 수 없으니 거절한다. 손절가가 하한가보다 낮으면
  하한가에 묶일 때 체결이 안 될 수 있다고 경고한다.
- **청산 시각.** 기본 15:15. 15:20 부터는 종가 단일가라 접속매매로 팔 수 없으니 그보다 늦게 잡으면
  거절한다. 개장이 늦은 날은 접속매매 끝에 맞춰 옮긴다. 진입이 청산 시각보다 늦으면 거절한다.
- **min_reward_risk** 는 여기서는 알리기만 한다. 막는 것은 `/trader-kr-risk` 다.

## 절차

1. `/trader-kr-entry` 가 신호를 냈으면 `exit.py plan` 을 돌린다. 아직이면 `--entry 가격` 으로 미리 계획한다.
2. 손절과 목표, 주당 위험, 순손익비, 청산 시각을 사용자에게 말한다. 경고가 있으면 같이 말한다.
3. 사용자가 받아들이면 `--write` 로 저장한다.
4. `/trader-kr-timemachine` 으로 다시 돌려 보고, `/trader-kr-budget` 으로 수량을 정한다.

## 예시 (합성 자료)

```
청산 계획: SYN001 합성종목 매수, 2026-10-28, 시가 범위 돌파, 5분봉
  진입        30,450 10:15 (14번째 봉)
  손절        30,100  시가 범위 중간값: (30,300 + 29,900) / 2 = 30,100
  목표        31,150  2R (위험의 두 배)
  주당 위험   350원 (진입가의 1.15%)
  손익비      2.00 (비용 뺀 순손익비 1.50, 수수료 0.015%, 매도세 0.20%)
  가격제한    하한가 21,000, 상한가 39,000 (전일 종가 30,000 기준 추정)
  청산 시각   15:15, 이기든 지든: 다음 날로 넘기지 않음
```

2R 이 비용을 빼면 1.50 이 된다. 위험이 가격의 1% 남짓인 단타에서는 매도 거래세 0.20% 가 크다.

## 지킬 것

- 손절은 계획이지 보장이 아니다. 갭, 급락, 하한가, VI 단일가 중에는 손절가보다 나쁘게 체결되거나
  체결되지 않을 수 있다. 사용자에게 이 말을 줄이지 않는다.
- 손절가에 닿으면 나온다. 손절가를 더 멀리 옮기자는 말에는 새 계획을 만들자고 답한다.
- 매수만.

## 하지 않는 것

주문을 내지 않고, 수량을 정하지 않고 (그건 `/trader-kr-budget`), 손절을 진입 뒤에 넓히지 않는다.

## 안전

- 교육과 도구일 뿐 투자 권유가 아닙니다 (not financial advice). PASS 는 규칙 점검이지 추천이 아닙니다.
- 주문은 trader-kr-broker 만 냅니다. 한국투자증권 모의투자 계좌로만 보내고, 이 팩의 어떤 스크립트도 토스증권
  주문·계좌 API 나 실전 계좌를 부르지 않습니다.
- 기본값은 보내지 않음 (`"send_orders": false`) 이고, 바꾸는 것은 사용자입니다. 주문은 세 가지가 모두 맞을 때만
  나갑니다: trader-kr-risk 가 오늘 그 주문 그대로 통과시켰고, 사용자가 채팅에서 그 주문 하나에 yes 라고 했고,
  Claude 의 도구 승인 카드에서 한 번만 허용을 눌렀을 때.
- 미수, 신용, 공매도는 쓰지 않습니다.
- 토스증권 client_id 와 client_secret 은 `~/.tossinvest/credentials.json` 또는 환경변수에 두고 채팅에 붙여 넣지 않습니다.
- 토스증권 자료는 본인 매매 목적으로만 씁니다. `trader-kr/cache/` 를 공유하거나 저장소에 올리지 않습니다.
