# trader-kr-insider

상장회사의 임원과 주요주주는 자기 회사 주식을 사고팔면 보고해야 하고, 이 보고는 DART 에 공개된다. 이 스킬은 그
보고가 올라오면 알아채고 원문을 읽어 거래 줄로 바꾼다. 원본(미국판 trader-pelosi)은 미국 하원의원의 거래 보고를
읽었다. 국내판은 회사 내부자의 보고를 읽는다.

두 보고는 시점이 다르다.

| 보고 | 언제 내나 | 근거 |
| --- | --- | --- |
| 소유상황보고서 | 변동이 있는 날부터 5일까지. 토요일·공휴일·근로자의 날은 세지 않는다. 장내 매매의 변동일은 결제일이다 | 자본시장법 제173조 ①, 시행령 제200조 ①·④, 제153조 ① |
| 거래계획보고서 | 거래기간 개시일 30일 전까지. 거래기간은 30일 이내 | 법 제173조의3 ①, 시행령 제200조의3 ③·④ |

소유상황보고는 빠르지만 이르지 않다. 결제일부터 며칠 뒤에 나오니, 읽을 때면 거래는 이미 끝났다. 거래계획보고는
사기 전에 나오지만 계획일 뿐이다. 거래금액의 30% 범위에서 달리 거래할 수 있고(시행령 제200조의3 ⑥), 사망·파산·큰
가격 변동 같은 사유로 철회할 수 있다(법 제173조의3 ④). 둘 다 공개된 보고다. 미공개 정보가 아니라는 점을 매번 말한다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/insider.py"                                # 관심 종목의 새 보고, 원문까지
python "${CLAUDE_SKILL_DIR}/insider.py" --symbols 005930 --days 90     # 한 종목의 지난 90일
python "${CLAUDE_SKILL_DIR}/insider.py" market                         # 시장 전체 새 보고 목록 (유가·코스닥)
python "${CLAUDE_SKILL_DIR}/insider.py" market --plans --read          # 거래계획만, 원문의 계획 줄까지
python "${CLAUDE_SKILL_DIR}/insider.py" show 20261120000525            # 보고 하나
```

`--all` 은 이미 본 것까지, `--json` 은 기계용, `--dry-run` 은 본 것으로 기록하지 않음, `--max-read N` 은 원문을
읽을 보고 수(기본 20), `--now "2026-11-20 18:30"` 은 시계 고정. 종료 코드는 새 보고 0, 없음 1, 오류 2.

## 읽고 쓰는 것

| 파일 / 자료 | 무엇 |
| --- | --- |
| `--symbols`, 없으면 `trader-kr/watchlist.json`, `plan.json`, `today/*/plan.json`, `journal.jsonl` | 관심 종목. 일지의 열린 거래는 "보유 중" 표시에도 쓴다 |
| OpenDART 고유번호 (`corpCode.xml`) | 종목코드를 회사 고유번호로. 30일마다 다시 받는다 (대가 점검표와 같은 캐시) |
| OpenDART 공시검색 (`list.json`) | 관심 종목은 회사별로, 시장 전체는 하루 전체 목록(공시 알림과 같은 캐시)에서 두 보고만 고른다 |
| OpenDART 공시서류원본파일 (`document.xml`) | 원문. 생년월일·주소·전화번호·이메일·업무 담당자 이름은 가린다 |
| `trader-kr/state/insider.json` | 보여 준 접수번호 (30일) |

## 규칙

- **원문을 옮긴다.** 수량, 단가, 날짜는 원문에서 뽑은 그대로 쓰고 접수번호와 링크를 단다. 뽑은 줄 수가 원문 표와
  맞는지 의심스러우면 `show` 나 `/trader-kr-news read 접수번호` 로 원문을 읽는다. "원문에서 거래 줄을 찾지 못했습니다"
  가 나오면 짐작하지 말고 원문을 읽는다.
- **사유를 구분한다.** 장내매수·장내매도만 시장에서 사고판 것이다. 증여, 수증, 상속, 자사주상여금, 전환권 행사,
  시간외매매는 다르다. 금액은 장내 매매 줄만 더하고, 다른 줄의 단가는 매매가로 읽지 않는다.
- **종류를 섞지 않는다.** 보통주와 우선주는 따로 더한다.
- **누구인지 말한다.** 등기·비등기 임원과 직위, 10% 이상 주주, 사실상 지배주주, 법인 보고자를 구분한다. 보고자가
  법인이면 그 법인의 거래다.
- **늦었는지 말한다.** 마지막 변동일부터 접수까지 평일 수를 보인다. 공휴일을 빼지 않은 어림이라 5일을 넘으면
  "넘었을 수 있음" 으로만 말한다. 주식배당·분할·병합·감자 같은 사유는 다음 달 10일까지 보고할 수 있다
  (시행령 제200조 ⑧).
- **모든 거래가 보고되는 것은 아니다.** 변동 수량 1천 주 미만이면서 금액 1천만 원 미만인 변동은 소유상황보고를
  하지 않아도 된다(시행령 제200조 ⑤). 거래계획은 6개월 합산이 발행 주식의 1% 미만이면서 50억 원 미만이거나, 상속이나
  주식배당으로 받는 것, 공개매수로 사는 것 같은 정해진 사유의 거래면 내지 않는다(시행령 제200조의3 ②·⑤).

## 단계

1. `python "${CLAUDE_SKILL_DIR}/insider.py"` 를 돌린다. 장 전에는 `market --plans --read` 로 새 거래계획도 본다.
2. 보고마다 한 줄로 적는다: 누가(관계), 무엇을(사유, 종류, 수량, 단가), 언제(결제일 또는 계획 기간), 늦었는지,
   보유 중인지, 접수번호와 링크.
3. 끝에 매번 말한다: "공개된 보고이고, 거래는 며칠 전에 끝났거나 아직 계획입니다. 이것이 주가 방향을 말해 주지
   않습니다."
4. 사용자가 이것으로 거래하려 하면 먼 길로 간다. 보고는 차트를 볼 이유일 뿐 셋업이 아니다. `/trader-kr-scanner` 와
   `/trader-kr-entry` 가 오늘 거래가 있는지 정하고, `/trader-kr-budget`, `/trader-kr-risk`, 사용자의 yes 를 거친다.

DART 목록은 낮 동안 계속 쌓인다. 장 중에는 `/loop 1h /trader-kr-insider` 나 예약 작업이면 충분하다.

## 예: 2026-11-21 에 돌린 것

`market --plans --read --since 2026-11-20` 의 한 건:

```
[거래계획] 025900 동화기업 2026-11-20 접수, 보고자 DONGWHAINTERNATIONALCO.,LTD (코스닥, 주요주주 10%이상주주)
    계획: 시간외매매(-) 보통주 5,763,531주 @4,975원 (약 286.74억원), 2026-12-21 ~ 2026-12-31 (11일)
    목적: 지분 매각 통한 유동성 확보 및 해외자회사 AMPC 세액공제를 위한 지분조정
```

주요주주인 법인이 12월 21일부터 11일 동안 시간외매매로 팔 계획이다. 수량과 단가는 예상치이고, 금액의 30% 범위에서
달라지거나 철회될 수 있다고 함께 적는다.

`show 20261120000593` (소유상황):

```
[소유상황] 131100 (주)티엔엔터테인먼트 2026-11-20 접수, 보고자 (주)초록뱀미디어 (주요주주 10%이상주주, 변동)
    장내매수(+) 보통주 +4,811주 @3,992원, 결제·변동일 2026-11-17, 거래계획 2026-09-22 보고분
    ...
    합계 보통주 +124,373주. 장내 매매 금액 4.97억원 (4줄). 변동 후 보통주 4,565,977주.
```

네 줄 모두 9월 22일에 낸 거래계획에 따른 매수이고, 마지막 결제일 2026-11-20 에 같은 날 보고했다.

## 하지 않는 것

- 임원이나 주요주주가 미공개 정보를 가졌다고 말하거나 암시하지 않는다. 따라 사면 낫다는 말, 수익 주장을 하지 않는다.
- 계획 수량을 확정된 거래처럼, 어림 평일 수를 확정된 기한 위반처럼 말하지 않는다.
- 가린 개인 정보(생년월일, 주소, 연락처)를 다른 곳에서 찾아 채우지 않는다.
- 주문을 내지 않는다.

## 안전

- 교육과 도구일 뿐 투자 권유가 아닙니다 (not financial advice).
- 이 스킬은 읽고 보여 주기만 합니다. 주문은 trader-kr-broker 만 냅니다. 한국투자증권 모의투자 계좌로만 보내고,
  trader-kr-risk 가 그 주문을 통과시키고, 사용자가 채팅에서 그 주문 하나에 yes 라고 하고, Claude 의 도구 승인
  카드에서 한 번만 허용을 눌렀을 때만 나갑니다.
- DART 키는 환경변수 `DART_API_KEY` 나 `python krcommon/keys.py dart` 로 등록한 파일에 두고 채팅에 붙여 넣지 않습니다.
