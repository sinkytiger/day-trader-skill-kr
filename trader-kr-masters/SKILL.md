# trader-kr-masters

대가 점검표는 "그레이엄이 세운 기준에 이 회사 숫자가 맞나" 를 기준 하나씩 보여 준다. 숫자를 지어낼 틈이 없도록
계산은 모두 스크립트가 DART 공시 원값과 KRX 시가총액으로 한다. Claude 의 일은 그 숫자를 각 대가의 관점으로 풀어
쓰는 것이고, 사라고 하거나 팔라고 하는 것이 아니다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/masters.py" check --symbol 005930                # 최근 10 사업연도
python "${CLAUDE_SKILL_DIR}/masters.py" check --symbol 005930 --years 6 --json
python "${CLAUDE_SKILL_DIR}/masters.py" find --name 삼성전자                   # 이름으로 종목코드 (기억으로 쓰지 않기)
```

회사 이름만 들었으면 기억하는 코드를 쓰지 말고 `find` 로 찾는다. 이 스킬의 순서를 한 번에 돌려 한 장으로 돌려주는
에이전트는 `@agent-day-trader-skill-kr:trader-kr-analyst` 다 (`agents/trader-kr-analyst.md`).

## 읽고 쓰는 것

| 자료 | 내용 |
| --- | --- |
| DART corpCode.xml | 종목코드 -> 회사 고유번호. `trader-kr/cache/dart/corpcode.json`, 30일마다 다시 받음 |
| DART fnlttSinglAcntAll | 사업보고서 전체 재무제표. 연결이 없으면 별도. `trader-kr/cache/dart/fs/` |
| DART alotMatter | 배당에 관한 사항 (보통주 주당 현금배당금, 현금배당금총액). `trader-kr/cache/dart/div/` |
| KRX 일별매매정보 | 가장 최근 거래일 종가, 상장주식수, 시가총액 (보통주 + 같은 회사 우선주) |

키: `DART_API_KEY` (또는 `~/.dart/api_key`), KRX 키 (`~/.krx/api_key`). KRX 키가 없으면 PER·PBR 같은 가격 기준은
"자료 없음" 이 된다. 처음 한 회사에 DART 호출 약 25번, 몇 초 걸린다. 그다음은 캐시에서.

## 기준

기준값은 대가들이 쓴 기준을 한국 자료에 맞춰 이 스크립트가 정한 것이다. 화면에 원래 기준과 바꾼 점을 같이 적는다.

**그레이엄 (『현명한 투자자』 의 방어적 투자자)**

| 번호 | 기준 | 원래와 다른 점 |
| --- | --- | --- |
| G1 | 매출 1조 원 이상 | 원래 1971년 미국 매출 1억 달러 |
| G2 | 유동비율 2.0 이상 | |
| G3 | 비유동부채 <= 순유동자산 | 원래 장기 부채. 비유동부채 전체라 더 엄격 |
| G4 | 자료 있는 모든 해 흑자 (5년 이상) | 원래 10년 |
| G5 | 자료 있는 모든 해 현금배당 (5년 이상) | 원래 20년 |
| G6 | 최근 3년 평균 순이익 >= 첫 3년 평균 x 4/3 | 원래 10년 사이 1/3 이상 |
| G7 | 시가총액 / 최근 3년 평균 순이익 <= 15 | |
| G8 | PBR <= 1.5, 또는 PER x PBR <= 22.5 | |

**버핏**: B1 평균 ROE 15% 이상, B2 ROE 가 10% 아래인 해 없음, B3 최근 3년 영업이익률 >= 첫 3년, B4 부채비율 100% 이하,
B5 잉여현금흐름(영업활동현금흐름 - 유형자산 취득)이 80% 이상의 해에서 플러스, B6 지배주주 자본 연 10% 이상 성장,
B7 최근 5년 유보이익(순이익 - 배당)보다 시가총액이 더 늘었음 (주주서한의 "유보한 1달러가 시가 1달러 이상" ).
참고로 이익수익률과 잉여현금 수익률을 낸다 (국고채 금리와 견줘 보는 숫자, 금리 자료는 넣지 않음).

**린치 (『전설로 떠나는 월가의 영웅』)**: 순이익 5년 연복리로 유형을 나눈다 (20% 이상 고성장, 10~20% 우량 성장, 그
아래 저성장, 적자에서 흑자로 회생, 흑자·적자가 두 번 넘게 바뀌면 경기순환·불규칙). L1 PEG 1 이하, L2 (성장률 +
배당수익률) / PER 1 이상, L3 매출이 늘고 영업이익률이 5년 전보다 낮지 않음, L4 재고 증가율 <= 매출 증가율,
L5 비유동부채 / 자본 33% 이하 ("자본 75 : 부채 25"), L6 최근 5번 중 4번 이상 순이익 증가.

ROE 는 지배주주 순이익 / 평균 지배주주 자본, 순이익은 모두 지배주주 몫이다.

## 결과 말하는 법

1. 연도별 표와 대가별 "N개 중 M개 충족" 줄을 그대로 보여 준다. 숫자를 바꾸거나 더하지 않는다.
2. 대가마다 두세 문장으로 "그 기준으로 보면 이 숫자가 어떻게 읽히는지" 를 쓴다. 출력에 있는 숫자만 쓴다.
   - 그레이엄: 안전마진(가격 대 이익·장부가), 재무 튼튼함, 이익 안정.
   - 버핏: 높은 자본이익률이 꾸준한지, 현금을 실제로 버는지, 유보이익이 가치로 이어졌는지.
   - 린치: 어떤 유형의 회사인지, 그 성장을 얼마에 사는 셈인지(PEG), 매출과 재고가 이야기를 뒷받침하는지.
3. 쓰지 않는 것: 사라·팔라, 강세·약세, 목표가, "지금이 기회", 출력에 없는 숫자, 사업보고서 접수일 뒤의 일.
4. "자료 없음" 이 많으면 그 대가의 틀로는 판단할 숫자가 모자란다고 말한다 (금융업이 그렇다).
5. 이 해석은 과거로 검증하지 않았고, 할 수도 없다고 말한다. 모델이 그 회사의 이후 결과를 이미 알기 때문이다.
   확인은 판단을 적어 두고 앞으로의 결과로만 할 수 있다 (`/trader-kr-journal`). 규칙으로 바꿀 수 있는 기준
   (저PER·저PBR·유동비율 등)은 `/trader-kr-invest` 처럼 미리 정해 두고 따로 시험할 수 있다.

## 가격이 깔고 있는 가정 (implied.py)

점검표가 "기준에 맞나" 라면, 이것은 "지금 시가총액이 앞으로에 대해 무엇을 전제하나" 를 거꾸로 푼다. 답은 숫자 몇
개이고, 그 숫자가 그럴듯한지는 사람이 지난 숫자와 견줘 판단한다.

```bash
python "${CLAUDE_SKILL_DIR}/implied.py" --symbol 005930                 # 밴드, 역DCF, 필요한 ROE
python "${CLAUDE_SKILL_DIR}/implied.py" --symbol 005930 --r 0.07 --r 0.09 --terminal 0.01 --horizon 10 --json
python "${CLAUDE_SKILL_DIR}/implied.py" --symbol 005930 --no-band       # 월말 KRX 표를 받지 않고 지금 값만
```

1. **밴드.** 첫 사업보고서가 나온 달부터 지난달까지 달마다 마지막 거래일의 시가총액(보통주 + 우선주)을, 그날 알던
   마지막 사업보고서의 지배주주 순이익·지배주주 자본·현금배당금총액과 견준다 (PER, PBR, 배당수익률). "그날 알던" 은
   그 숫자를 준 보고서의 정정 전 첫 접수일 기준이다 (OpenDART 공시 목록). 그 해 재무제표가 비어 다음 해 보고서의
   전기 값을 쓰면 다음 해 보고서가 나온 뒤부터 센다. 지금 값과 가장 낮음·25%·가운데·75%·가장 높음, 지금보다 낮았던
   달의 비율을 낸다. PER 은 적자이던 달을 뺀다. 배당수익률은 총액 / 시가총액이라 액면분할에 흔들리지 않는다.
2. **역DCF.** 지금 시가총액이 앞으로 잉여현금흐름(영업활동현금흐름 - 유형자산 취득)의 현재가치라면 앞 N년(기본 10)
   동안 연 몇 % 늘어야 하는지 푼다. 출발은 최근 3년 평균, N년 뒤에는 연 terminal(기본 2%)로 는다. 할인율마다 한
   줄. 찾는 범위는 연 -50% ~ +100% 이고 밖이면 그렇게 적는다. 유동·비유동 구분이 없는 재무제표(금융업)와 3년 평균이
   0 이하인 회사는 풀지 않는다.
3. **필요한 ROE (잔여이익모형).** 시가총액 = 지배주주 자본 + 앞으로 초과이익((ROE - r) x 자본)의 현재가치가 되려면
   ROE 가 영원히 얼마여야 하나. 이익을 모두 배당해 자본이 그대로일 때 ROE = r x PBR. 지난 3년 배당성향대로 남겨
   자본을 ROE x 남기는 몫(b)만큼 키울 때 PBR = (ROE - g) / (r - g), g = ROE x b 에서 ROE = PBR x r / (1 - b + PBR x b).
   남기는 판은 자본 성장 g 를 같이 적는다. g 가 r 에 가까울수록 작은 차이에 크게 흔들린다.

할인율 r 은 가정이다. 기본으로 6·8·10% 세 줄을 함께 보여 주고, `--r` 로 바꾼다 (terminal 보다 커야 함). 처음 한 번은
월말 KRX 표 약 130개를 받는다 (몇 분, 표 하나 약 0.5MB, `trader-kr/cache/krx/`). 표는 모든 회사가 같이 쓰니 두 번째
회사부터는 거의 받지 않는다. DART 는 점검표와 같은 캐시에 사업보고서 접수 기록(`filings/`)이 더해진다.

말할 때:

1. 세 표를 그대로 보여 준다. 숫자를 바꾸거나 더하지 않는다.
2. "지금 가격은 할인율 8% 에서 앞 10년 잉여현금이 연 x% 늘어난다는 가정과 맞먹는다. 지난 n년 매출은 연 y%,
   순이익은 연 z% 였다" 처럼 가정과 지난 숫자를 나란히 적는다. 그 차이를 싸다·비싸다, 저평가·고평가, 적정 주가,
   목표가로 바꾸지 않는다.
3. 할인율을 하나로 정해 주지 않는다. 세 줄이 얼마나 다른지가 이 숫자가 가정에 얼마나 기대는지 보여 준다.
4. 밴드의 "지금보다 낮았던 달" 은 이 회사의 지난 값 가운데 위치일 뿐이다. 업종이 바뀌었거나 이익이 한 해 크게
   흔들린 회사는 밴드가 기준이 되기 어렵다고 말한다.

한계: 사업보고서(연간)만 쓴다 (분기 이익 없음). 빚과 현금을 따로 조정하지 않아, 잉여현금흐름은 이자를 낸 뒤일 수
있고 순현금이 많은 회사는 역산 성장률이 높게 나온다. 연결에 할부·카드 같은 금융 자회사가 있으면 영업현금흐름에
대출이 섞인다. 모델의 꼴과 기본 가정은 이 저장소가 정했다. 역산 가치평가의 생각은 Rappaport and Mauboussin
『Expectations Investing』(2001), 잔여이익모형은 Ohlson (1995) 에서 왔고 글이나 코드는 옮기지 않았다.

## 한계

- DART 전체 재무제표는 2015 사업연도부터다. 그래서 10년, 20년 기준은 자료 기간으로 줄여 잰다.
- 은행·보험·금융지주는 전체 재무제표가 2023 사업연도(일부는 2022)부터만 있는 경우가 있다 (KB금융 2026-11 실측).
  유동·비유동 구분도 없다.
- 사업보고서(연간)만 쓴다. 분기 실적, 올해 들어 바뀐 것은 들어 있지 않다.
- 주당배당은 그 해 보고서 금액이라, 액면분할 전 해는 분할 전 금액이다 (있다·없다 판정에만 쓴다).
- 시가총액은 보통주와 같은 회사 우선주(종목 코드 앞 5자리가 같음)를 더한다.
- 기준값과 바꾼 점은 이 스크립트가 정한 것이다. 대가 본인의 판단이 아니다.

## 논지 추적 (thesis)

린치가 말한 "왜 갖고 있는지 알라" 를 기록으로 남긴다. 대가 해석은 과거로 검증할 수 없으니, 판단을 미리 적어 두고
앞으로의 숫자와 공시로 다시 보는 것이 유일한 확인 방법이다.

```bash
python "${CLAUDE_SKILL_DIR}/masters.py" thesis new --symbol 005930 --statement "논지 한두 문장" \
  --pillar "매출이 다시 큼 | 매출성장 >= 5%" --pillar "이익률 회복 | 영업이익률 >= 12%" \
  --risk "빚이 늘어남 | 부채비율 > 60%" --risk "비싸짐 | PER > 30" --risk "중국 경쟁" \
  --catalyst "2027-01-08 | 4분기 잠정 실적"
python "${CLAUDE_SKILL_DIR}/masters.py" thesis add --symbol 005930 --data "무엇이 바뀌었나" --impact P2:강화 --conviction 보통
python "${CLAUDE_SKILL_DIR}/masters.py" thesis add --symbol 005930 --done "C1:영업이익 시장 예상 웃돎"
python "${CLAUDE_SKILL_DIR}/masters.py" thesis check --symbol 005930     # 숫자 판정, 지난 점검 뒤 공시, 촉매
python "${CLAUDE_SKILL_DIR}/masters.py" thesis show --symbol 005930      # 네트워크 없이
python "${CLAUDE_SKILL_DIR}/masters.py" thesis list                      # 분기 넘게 안 본 논지 표시
python "${CLAUDE_SKILL_DIR}/masters.py" thesis metrics                   # 조건에 쓸 지표 12개
```

- **논지 정의.** 논지 한두 문장, 근거(`--pillar`), 논지를 깨뜨릴 위험(`--risk`, 하나 이상 필수: 반증할 수 없는
  논지는 논지가 아니다), 촉매(`--catalyst "날짜 | 사건 | 기대"`), 사용자가 정한 목표와 손절 조건(`--target`,
  `--exit`, 적기만 한다). 매수 논지만 다룬다. 이미 있으면 덮어쓰지 않는다. `trader-kr/thesis/<종목>.json`.
- **숫자 조건.** "설명 | 지표 연산 값" (예: `매출성장 >= 5%`, `PER <= 15`, `잉여현금 > 10조`). 근거는 조건이 맞으면
  충족, 위험은 조건이 맞으면 "일어남". 조건 없는 근거·위험은 사용자가 `--impact` 로 적은 기록만 보여 준다.
- **갱신 기록.** `thesis add --data` 에 날짜, 무엇이 바뀌었나, 어느 근거·위험을 강화·약화·중립시키는지, 사용자가 정한
  조치와 확신도(높음·보통·낮음)를 적는다. 반대 증거도 같은 무게로 적는다.
- **점검.** `thesis check` 가 최근 사업보고서와 시가총액으로 숫자 근거·위험을 다시 판정하고, 지난 점검 값과 비교한
  추세(좋아짐·나빠짐·같음), 지난 점검 뒤 DART 공시(실적·증자 같은 공시는 [!]), 지난 촉매와 다가올 촉매(120일)를
  보여 준다. 점검 기록이 파일에 남는다 (`--dry-run` 이면 남기지 않음).
- **분기마다.** 아무 일이 없어도 92일이 넘으면 `thesis show`, `thesis list` 가 점검할 때라고 알린다.

말할 때: 점수표와 공시 목록을 그대로 보여 주고, 위험이 "일어남" 이면 그 사실과 사용자가 적어 둔 손절 조건을 같이
보여 준다. 늘려라·줄여라·팔아라 같은 조치는 말하지 않는다. 조치 칸은 사용자가 채운다. 숫자는 연간 사업보고서 기준이라
분기 실적은 공시 목록으로만 보인다고 말한다.

  나갑니다: trader-kr-risk 가 오늘 그 주문 그대로 통과시켰고, 사용자가 채팅에서 그 주문 하나에 yes 라고 했고,
  Claude 의 도구 승인 카드에서 한 번만 허용을 눌렀을 때.
- 미수, 신용, 공매도는 쓰지 않습니다.
- DART 키와 KRX 키는 `~/.dart/api_key`, `~/.krx/api_key` 또는 환경변수에 두고 채팅에 붙여 넣지 않습니다
  (`python krcommon/keys.py dart`, `python krcommon/keys.py krx` 를 본인 터미널에서).
