# trader-kr-earnings

실적은 달력에서 주가를 가장 크게 흔드는 일이고, 보도자료는 가장 좋은 숫자를 앞에 놓는다. 이 스킬은 회사가 실제로
금융감독원에 낸 숫자를 분기마다 줄 세우고 무엇이 바뀌었는지 말한다. 단타 전에 두 가지를 답한다: 지난 보고서는
무엇을 말했나, 다음 보고서나 잠정실적이 이 거래 안에 들어오나.

원본(미국판 trader-analyst)은 SEC XBRL 을 읽었다. 국내판은 OpenDART 단일회사 전체 재무제표를 읽는다. 연결재무제표가
있으면 연결, 없으면 별도다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/earnings.py" 005930                     # 최근 8분기
python "${CLAUDE_SKILL_DIR}/earnings.py" 005930 000660 --quarters 12
python "${CLAUDE_SKILL_DIR}/earnings.py" --json                     # 관심 종목 전부, 기계용
python "${CLAUDE_SKILL_DIR}/earnings.py" 005930 --refresh           # 정정 보고서가 나왔을 때 캐시를 무시
```

## 읽고 쓰는 것

| 파일 / 자료 | 무엇 |
| --- | --- |
| 종목코드, 없으면 `trader-kr/` 의 관심 종목 | 스캐너 결과, 계획, 일지의 열린 거래 |
| OpenDART 고유번호, 기업개황 | 종목코드를 회사 고유번호로, 결산월 (대가 점검표와 같은 캐시) |
| OpenDART 단일회사 전체 재무제표 (`fnlttSinglAcntAll`) | 1분기(11013), 반기(11012), 3분기(11014), 사업보고서(11011). 손익계산서 줄만 `trader-kr/cache/dart/fsq/` 에 둔다 |
| OpenDART 공시검색 | 최근 정기보고서 뒤에 나온 잠정실적·손익구조변경 공시 |

## 규칙

- **낸 숫자가 먼저다.** 표는 회사가 낸 재무제표 값이다. 잠정실적 공시나 보도자료는 맥락으로 쓰고, 어느 숫자가 어디서
  왔는지 말한다.
- **같은 것끼리 견준다.** 전년비는 같은 보고서에 다시 적힌 전년 같은 분기와 견준 값이다. 직전 분기와의 차이는 계절을
  탄다 (반도체, 유통, 건설은 분기마다 다르다).
- **계산한 것은 계산했다고 말한다.** 4분기 보고서는 따로 없다. 4분기는 사업보고서 연간 값에서 3분기 누적을 뺀 값이고
  `*` 를 붙인다. 계산한 4분기 EPS 는 주식 수가 바뀌면 어긋나는 어림이다. 연결과 별도가 섞이면 계산하지 않는다.
- **자료가 늦으면 말한다.** 정기보고서보다 새 잠정실적 공시가 있으면 `!` 줄이 나온다. 그 공시를 `/trader-kr-news`
  의 `news.py read 접수번호` 로 읽고 나서 요약한다. 잠정실적은 정기보고서보다 먼저 낸 숫자라 바뀔 수 있다고 함께 말한다.
- **일회성을 짚는다.** 순이익이 영업이익보다 크면 금융·지분법·자산 처분 같은 영업 밖 이익이 들어 있다는 줄이 나온다.
  금융지주·은행·보험처럼 매출 줄이 없는 회사는 이익률을 비운다. 0 이 아니라 없음이다.
- **결산월을 본다.** 12월 결산이 아니면 분기 이름은 사업연도 기준이고 다음 보고서 기한은 계산하지 않는다.

## 다음 보고서는 언제

법정 기한은 분기·반기보고서가 그 기간이 끝난 뒤 45일 이내 (자본시장법 제160조 ①), 사업보고서가 사업연도가 끝난 뒤
90일 이내다 (제159조 ①). 말일이 토요일이나 공휴일이면 다음 날로 미뤄진다 (민법 제161조). 스크립트는 토·일만 미루고
공휴일은 모른다. 연결재무제표 기준으로 처음 쓰는 반기·분기보고서는 그 첫 사업연도와 다음 사업연도에 60일까지 낼 수
있다 (제160조 ①). 기한은 실제 발표일이 아니다. 잠정실적을 그보다 먼저 공정공시로 내는 회사도 있다. 날짜를 말할 때는 어디서 왔는지
("법정 기한", "회사 IR 일정", "잠정실적 공시") 를 붙인다.

## 단계

1. `python "${CLAUDE_SKILL_DIR}/earnings.py" 종목코드` 를 돌린다.
2. `!` 줄이 있으면 그 공시를 먼저 읽는다.
3. 요약은 세 줄로 쓴다: 최근 분기 (매출, 영업이익, 순이익의 전년비), 이익률, 눈에 띄는 것 (적자 전환, 일회성, 계산한
   4분기, 늦은 자료). 숫자가 받쳐 주지 않는 형용사는 쓰지 않는다.
4. 다음 보고서나 잠정실적이 계획한 거래 안에 들면 `/trader-kr-exit` 가 손절을 정하기 전에 말한다: 손절은 갭을 막지
   못한다. 장 마감 전에 끝나는 단타는 장 마감 뒤 공시에는 노출되지 않지만 장중 공시에는 노출되고, 하룻밤 들고 가면
   둘 다 노출된다.

## 예: 2026-11-21 에 돌린 것

`earnings.py 005930` 의 일부:

```
005930 삼성전자(주) (연결, 12월 결산)
  최근 보고서: 2026 3분기보고서, 2026-11-16 접수 (접수번호 20261116001482)
  분기            매출    전년비   영업이익    전년비  영업률     순이익    전년비       EPS
  2026 3Q     195.25조   +126.9%   107.44조   +783.1%   55.0%    75.21조   +526.4%    11,462
  2025 4Q*     93.84조    +23.8%    20.07조   +209.2%   21.4%    19.29조   +154.6%     2,881
  최근 4분기 합 (2025 4Q ~ 2026 3Q): 매출 594.46조, 영업이익 274.24조, 순이익 212.87조, EPS 32,315원
  다음 정기보고서: 2026 사업보고서, 법정 기한 2027-03-31 ...
```

2025년 4분기 매출 93.84조는 2025 사업보고서 연간 매출 333.61조에서 3분기 누적 239.77조를 뺀 값이다. 3분기보고서의
기한은 11월 14일이 토요일이라 11월 16일(월)로 미뤄졌고, 그날 접수됐다. 요약은 "3분기 영업이익 107.44조, 전년 같은 분기의 8.8배" 처럼
숫자로 쓰고, 다음 보고서의 법정 기한은 2027-03-31 이지만 잠정실적은 더 일찍 나올 수 있다고 덧붙인다.

## 하지 않는 것

- 주식이 싸다, 비싸다, 사라, 팔라고 말하지 않는다. 회사가 낸 숫자를 옮긴다.
- 재무제표에 없는 숫자를 지어내거나, 계산할 수 없는 분기를 짐작하지 않는다.
- 실적 발표일을 법정 기한으로 바꿔 말하지 않는다.
