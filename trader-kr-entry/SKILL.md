# trader-kr-entry

진입 타이머는 셋업을 한 순간으로 바꾼다. 그 셋업을 확인하는 봉이다. 5분봉(또는 1분봉)이
끝나기를 기다린다. 봉 중간에 고가를 잠깐 넘은 가격은 진입이 아니다. 고가 위에서 "끝난"
봉이 진입이다. 그 시각과 가격을 말하고, 청산 계획이 읽도록 적어 두고, 멈춘다. 아무것도
사지 않는다. 단타는 대부분의 사람에게 손해를 내고, 깨끗한 신호도 그 사실을 바꾸지 않는다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python` 대신 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/entry.py" check 005930                  # 15분 시가 범위, 5분봉
python "${CLAUDE_SKILL_DIR}/entry.py" check 005930 --write          # trader-kr/entry.json 에도 저장
python "${CLAUDE_SKILL_DIR}/entry.py" check 005930 --setup level --level 72000
python "${CLAUDE_SKILL_DIR}/entry.py" check 005930 --interval 1m --min-volume-x 1.5
python "${CLAUDE_SKILL_DIR}/entry.py" watch 005930 --until 14:50    # 봉이 끝날 때마다 한 줄, 신호면 멈춤
python "${CLAUDE_SKILL_DIR}/entry.py" watchlist                     # trader-kr/watchlist.json 의 종목 전부
```

그 밖의 옵션: `--or-minutes N` (기본 15), `--json`, `--offline FILE` (저장된 1분봉 파일 또는
`<종목>.json` 폴더), `--now "2026-10-28 10:15"` (한국 시간) 로 지난 장 다시 보기. `watch` 에
`--now` 나 `--offline` 을 주면 모의 시계로 기다리지 않고 하루를 봉 단위로 다시 돌린다.

## 읽고 쓰는 것

| 파일 | 내용 |
| --- | --- |
| `trader-kr/watchlist.json` | 스캐너 결과 (`hits[].symbol`), `watchlist` 용 |
| `trader-kr/config.json` | `no_entries_before` (09:15), `no_entries_after` (14:50). 선택 |
| 토스증권 1분봉 | 오늘 09:00 부터 지금까지. `trader-kr/cache/` 에 캐시 |
| 토스증권 장 운영 정보 | 오늘 개장·종가 단일가 시각. 개장이 늦은 날을 맞춘다 |
| `trader-kr/entry.json` | `check --write` 또는 `watch` 신호 때: 종목, 셋업, 상태, 시각, 봉, 가격, 기준, 시가 범위, 장 시간 |

## 규칙

- **시가 범위 (orb).** 개장 뒤 15분 고가와 저가: 09:00, 09:05, 09:10 5분봉. 넘을 기준은 범위 고가.
  09:00 봉에는 동시호가 체결이 들어 있다.
- **기준 가격 (level).** 직접 준 가격. 예: `/trader-kr-scanner` 의 20일 신고가.
- **신호**는 범위 뒤 처음으로 기준 "위에서 끝난" 완성 봉이다. 꼬리만 넘은 봉은 아니다. 기준과 같은
  가격에서 끝난 봉도 아니다.
- **시각**은 그 봉이 끝나는 시각 (10:10 봉이면 10:15), **가격**은 그 봉 종가.
- **끝난 봉만 센다.** 토스증권 1분봉 시각은 봉이 끝나는 시각이다. 5분봉은 안의 1분봉 다섯 개가
  다 끝나야 완성이다.
- **접속매매만 본다.** 09:00 ~ 15:20. 15:20 부터는 종가 단일가라 이 셋업에 쓰지 않는다.
  NXT 프리마켓·애프터마켓 봉도 쓰지 않는다.
- **거래량 조건 (선택).** `--min-volume-x 1.5` 면 신호 봉 거래량이 범위 봉 평균의 1.5배 이상이어야 한다.
- **시간 제한.** 09:15 전, 14:50 뒤에는 새로 진입하지 않는다 (설정). 신년 첫 거래일이나 수능일처럼
  개장이 늦은 날은 토스증권 장 운영 정보로 두 시각을 함께 옮긴다.
- **말하는 것.** 대기 (마지막 종가와 기준의 거리), 신호, 만료, 자료 없음. 09:00 전은 개장 전,
  09:15 전은 범위 형성 중. 주말·휴장일은 휴장.

## 절차

1. 사용자에게 종목을 받거나, `/trader-kr-scanner` 뒤 `entry.py watchlist` 를 돌린다.
2. `entry.py check 종목` 을 돌리고 상태를 한 줄로 말한다: 대기와 남은 거리, 신호 시각과 가격, 만료.
3. 기다려야 하면 `entry.py watch 종목 --until 14:50` 을 백그라운드로 돌리거나, `/loop` 로 5분마다
   `entry.py check 종목 --write` 를 돌린다. `watch` 는 봉이 끝난 직후 깨어 한 줄씩 찍고, 신호면 0
   (trader-kr/entry.json 기록), 만료면 1 로 끝난다. 지켜보는 동안 컴퓨터가 잠들지 않게 한다.
4. 신호가 나면 시각과 가격, 그리고 주문은 내지 않았다는 것을 말한다. 신호가 한 봉보다 오래됐으면
   그것도 말한다. 늦은 진입은 다른 거래다.
5. 사기 전에 `/trader-kr-exit` 로 손절가와 목표가를 정한다.

## 예시 (합성 자료)

시험용 합성 종목 SYN001, 2026-10-28, 5분봉. 실제 시세가 아니다. 시가 범위는 29,900 ~ 30,300.
10:15 에 10:10 봉이 끝났다:

```
SYN001 합성종목  2026-10-28 10:15  시가 범위 돌파 (15분 범위), 5분봉 (토스증권)
시가 범위 09:00~09:15: 고가 30,300, 저가 29,900 (3 / 3 봉).
신호 10:15, 30,450: 10:10 봉(14번째)이 범위 고가 30,300 위에서 끝났습니다 (+0.50%).
들어간다면 지금입니다. 주문은 내지 않았습니다.
다음: 사기 전에 손절가와 목표가부터 정하세요: /trader-kr-exit (exit.py plan --write).
```

10:13 에는 10:10 봉이 아직 만들어지는 중이라 대기라고 말한다.

## 지킬 것

- 신호는 정보다. 주문도 약속도 아니다. 이기는 거래나 돈을 약속하지 않는다.
- 매수만. 사용자가 공매도를 원하면 이 팩은 매수만 본다고 말한다.
- 셋업마다 하루 신호는 하나: 처음 위에서 끝난 봉. 뒤의 봉이 다시 세지 않는다.
- 봉이 위에서 끝날 것 같다고 미리 신호를 부르지 않는다.
- 토스증권 자료가 늦거나 빈 봉이 있으면 그렇다고 말한다.

## 하지 않는 것

주문을 내지 않고, 수량을 정하지 않고, 손절을 정하지 않고 (그건 `/trader-kr-exit`), 지난 뒤에
기준을 옮기지 않고, 끝나지 않은 봉을 세지 않는다.

## 안전

- 교육과 도구일 뿐 투자 권유가 아닙니다 (not financial advice). 신호와 PASS 는 규칙 점검이지 추천이 아닙니다.
- 1단계에는 주문을 보내는 도구가 없습니다. 이 팩의 어떤 스크립트도 토스증권 주문·계좌 API 를 부르지 않습니다.
- 토스증권 Open API 에는 모의투자 서버가 없습니다. 나중에 주문 단계를 붙여도 기본값은 보내지 않음
  (`"send_orders": false`) 이고, 주문은 세 가지가 모두 맞을 때만 나갑니다: trader-kr-risk 가 오늘 그 주문
  그대로 통과시켰고, 사용자가 채팅에서 그 주문 하나에 yes 라고 했고, Claude 의 도구 승인 카드에서 한 번만
  허용을 눌렀을 때.
- 미수, 신용, 공매도는 쓰지 않습니다.
- 토스증권 client_id 와 client_secret 은 `~/.tossinvest/credentials.json` 또는 환경변수에 두고 채팅에 붙여 넣지 않습니다.
- 토스증권 자료는 본인 매매 목적으로만 씁니다. `trader-kr/cache/` 를 공유하거나 저장소에 올리지 않습니다.
