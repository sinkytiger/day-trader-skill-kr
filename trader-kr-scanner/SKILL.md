# trader-kr-scanner

스캐너는 많은 차트를 같은 규칙으로 본다. 맞는 차트를 거래대금 많은 순(daily)이나 신호 시각 순(orb)으로
늘어놓을 뿐 고르지 않는다. 고르는 것은 사용자이고, 그다음은 `/trader-kr-entry` 다.

`${CLAUDE_SKILL_DIR}` 는 이 SKILL.md 가 있는 폴더다. macOS·리눅스에서는 `python3`.

```bash
python "${CLAUDE_SKILL_DIR}/scan.py" universe                       # 코스피·코스닥 보통주 -> trader-kr/universe.json
python "${CLAUDE_SKILL_DIR}/scan.py" daily                          # 장 전: 거래대금 상위 100 의 일봉 셋업
python "${CLAUDE_SKILL_DIR}/scan.py" daily --universe               # 전 종목 (몇 분 걸림)
python "${CLAUDE_SKILL_DIR}/scan.py" orb                            # 09:20 뒤: 지금까지 시가 범위 돌파
python "${CLAUDE_SKILL_DIR}/scan.py" orb --at 10:15 --or-minutes 15
python "${CLAUDE_SKILL_DIR}/scan.py" orb --symbols 005930,000660,035420
```

그 밖의 옵션: `--limit N`, `--include-preferred`, `--watchlist FILE`, `--min-price`, `--min-value` (daily),
`--show N`, `--no-write`, `--json`, `--offline DIR` 와 `--now "2026-10-28 10:15"` (저장한 파일로 다시 보기).

키가 아직 없거나 흐름부터 보고 싶으면 합성 자료 데모를 돌린다. 합성 종목 3개로 스캔부터 실험실까지 8단계를
5초쯤에 돌리고, 네트워크와 실제 키를 쓰지 않는다. 실제 시세가 아니라고 함께 말한다.

```bash
python "${CLAUDE_SKILL_DIR}/../krcommon/demo.py" --dir trader-kr-demo
```

## 읽고 쓰는 것

| 파일 | 내용 |
| --- | --- |
| 토스증권 랭킹 | 시장 거래대금 상위 100. orb 는 실시간, daily 는 1일 |
| 토스증권 종목 정보 | 후보 중 주식·보통주·ACTIVE·거래정지 아님·정리매매 아님만 남김 |
| KRX 일별매매정보 | daily: `KRX_API_KEY` 가 있으면 한국거래소 공식 일봉 60 거래일 (날짜마다 두 번 호출로 전 종목, 캐시) |
| 토스증권 일봉 / 1분봉 | daily 는 KRX 키가 없을 때만 종목마다 토스 일봉 60개, orb 는 오늘 09:00 부터 1분봉 (캐시) |
| `trader-kr/universe.json` | `universe` 결과. `--universe` 가 읽는다 |
| `trader-kr/watchlist.json` | 결과: 모드, 기준 시각, 후보 설명, 종목마다 셋업·가격·기준 (`level`) |

## 셋업

daily (종가만으로, 원본과 같은 계산):

| 셋업 | 조건 |
| --- | --- |
| 20일 종가 신고가 | 마지막 종가가 그 전 20일 종가보다 모두 높음 |
| 상승 깃발 | 마지막 5일 전 10일 동안 10% 넘게 오르고, 마지막 5일 종가가 5% 범위 안 |
| 20일 평균 회복 | 20일 평균 아래서 끝났다가 위에서 끝남 |
| 과매도 | RSI 14 (Wilder) 30 미만 |
| 과매도 반등 | 어제 RSI 14 가 30 미만이고 오늘 올라서 끝남 |

일봉은 KRX Open API 키가 있으면 한국거래소 공식 종가를 쓴다 (`--source krx`). 키 등록은 사용자가 본인 터미널에서
`python krcommon/keys.py krx` 로 한다 (Claude 가 키를 받아 입력하지 않는다). 없으면 토스 일봉을 쓰고
경고한다: 토스 일봉 종가는 KRX+NXT 통합이라 20:00 NXT 애프터마켓 마지막 가격이고, KRX 종가와 1% 넘게 다를 수 있다.
KRX 자료는 매일 08:00 에 전 거래일 것으로 올라온다. 처음 60 거래일을 받는 데 1분 반쯤 걸리고, 그다음부터는 몇 초다.
`--universe` 로 KRX 전 종목(약 2,500 보통주)을 훑어도 KRX 호출은 늘지 않는다. 결과의 `level` 은 20일 최고 종가라 `/trader-kr-entry --setup level`
기준으로 쓸 수 있다.

orb: 범위는 개장 뒤 15분. 범위 고가 = 범위 봉의 가장 높은 고가. 신호 = 범위 뒤 처음으로 그 위에서 끝난 완성 5분봉.
개장부터 기준 시각까지 5분봉이 하나도 빠짐없는 차트만 쓴다 (빈 봉은 거래정지나 자료 문제일 수 있다). 기준 시각이
새 진입 마감(14:50) 뒤면 늦었다고 말하고 멈춘다.

## 절차

1. 장 전에는 `scan.py daily`, 장중 09:20 뒤에는 `scan.py orb` 를 돌린다.
2. 몇 종목을 받았고 몇 종목이 맞았는지, 맞은 종목 위 몇 개를 말한다. 후보가 거래대금 상위 100 이라는 것도 말한다.
3. 사용자가 하나를 고르면 `/trader-kr-entry 종목` 으로 넘긴다. 스캔 결과로 사라고 권하지 않는다.

## 예시 (합성 자료)

```
시가 범위 돌파 스캔, 2026-10-28 10:15: 15분 범위 (09:00 ~ 09:15), 5분봉, 토스증권. 후보: 오프라인 1종목.
1종목 받음, 1종목 사용 가능.
1 / 1 종목이 10:15 까지 시가 범위 고가 위에서 끝났습니다:
  10:15  SYN001 합성종목       30,450  범위 29,900 ~ 30,300  +0.50%
```

## 지킬 것

- 스캔은 규칙에 맞는 차트 목록이지 살 종목 목록이 아니다. 이 문장을 결과와 함께 말한다.
- 토스증권 호출 한도를 지킨다 (스크립트가 쉬어 가며 부른다). 전 종목 스캔은 몇 분 걸린다고 미리 말한다.
- 일부 종목을 못 받았으면 그 수를 말한다.

## 안전

- 교육과 도구일 뿐 투자 권유가 아닙니다 (not financial advice). 스캔 결과와 PASS 는 규칙 점검이지 추천이 아닙니다.
- 1단계에는 주문을 보내는 도구가 없습니다. 이 팩의 어떤 스크립트도 토스증권 주문·계좌 API 를 부르지 않습니다.
- 토스증권 Open API 에는 모의투자 서버가 없습니다. 나중에 주문 단계를 붙여도 기본값은 보내지 않음
  (`"send_orders": false`) 이고, 주문은 세 가지가 모두 맞을 때만 나갑니다: trader-kr-risk 가 오늘 그 주문
  그대로 통과시켰고, 사용자가 채팅에서 그 주문 하나에 yes 라고 했고, Claude 의 도구 승인 카드에서 한 번만
  허용을 눌렀을 때.
- 미수, 신용, 공매도는 쓰지 않습니다.
- 토스증권 client_id 와 client_secret 은 `~/.tossinvest/credentials.json` 또는 환경변수에 두고 채팅에 붙여 넣지 않습니다.
- 토스증권 자료는 본인 매매 목적으로만 씁니다. `trader-kr/cache/` 를 공유하거나 저장소에 올리지 않습니다.
